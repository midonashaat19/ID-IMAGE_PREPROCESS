# Image Preprocessing

A Computer Vision project focused on image preprocessing techniques for Egyptian ID card analysis.

## Notebooks

### 1. HOW_SIFT_WORK
Explains SIFT feature detection, descriptors, feature matching, and image alignment using Homography and RANSAC.

### 2. HOW_TO_ROTATE
Explains image rotation correction using Canny Edge Detection and Hough Line Transform.

### 3. Distance_between_fields
Detects important ID card fields and measures the distances between their bounding boxes.

### 4. Height_of_word
Processes a text region using thresholding, morphological operations, and Connected Components to estimate text height in pixels.

## Technologies

- Python
- OpenCV
- NumPy
- Matplotlib
- SIFT
- Homography
- RANSAC
- Hough Transform
- Connected Components

## Objective

The goal is to understand and implement image preprocessing techniques required for accurate Egyptian ID card analysis and verification.
